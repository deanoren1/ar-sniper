# SnapBoo monster designs (approved direction, Nov 2026)

Binding style: tundra.jpg (clean glossy brawler-cartoon). 8 monsters per world (Classic 5), one ground boss per world that enters from a portal.
Rules: >=60% original per world, octopus recurs (charming, not angry), balloon role always floats, ~30% hiders, flyers fly, range of emotions per world, each monster has one dominant color for readability on photos.
Animation rows must match each body (flyers hover/fly instead of walking, hiders hide/pop out, no-leg monsters slide/drift, props stay on the same side).

Worlds: classic, tundra, jungle, cyberpunk, military, volcano (+ *_boss.jpg).
