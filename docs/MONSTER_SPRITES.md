# מפרט מפלצות מונפשות (rig) ל-SnapBoo

המשחק טוען מפלצות מונפשות מגיליון פריימים אחד לכל מפלצת, בלי שינוי קוד. מספיק להוסיף קובץ.

## שם הקובץ
`app/src/main/res/drawable/rig_<ארנה>_<סוג>_<n>.png` (או `.webp`)

- **ארנה:** `classic`, `tundra`, `jungle`, `military`, `ruins`, `market`, `cyber`, `forest`, `industrial`
- **סוג התנהגות:**
  - `0` ענק
  - `1` תמנון
  - `2` קיפוד
  - `4` חייזר
  - (`3` = מפלצת הבלונים: מיוחדת, לא נתמכת בגיליון rig)
- **n:** 0, 1, 2... (כל מפלצת חדשה מספר נוסף, בלי לדלג)
- דוגמה: `rig_tundra_1_0.png`, `rig_tundra_1_1.png`, `rig_classic_4_0.png`

המפלצת מצטרפת למאגר של הסוג בארנה הזאת ומתערבבת עם המפלצות הקיימות.

## הגיליון
- **פריסה:** 6 עמודות × 4 שורות, 24 תאים שווים.
- **גודל תא מומלץ:** 384×384 (גיליון 2304×1536). לבוס או ענק קרוב: 512×512.
- **רקע:** שקוף (PNG/WebP עם alpha). בלי מסגרת לבנה.
- **כיוון:** הדמות פונה ימינה בהליכה (המשחק הופך לשמאל לבד).
- **עוגן:** הרגליים על אותה שורה בכל הפריימים; הדמות במרכז התא, עם שוליים סביבה.
- **עקביות:** כל הפריימים נבנים מאותו שלד וחלקים (לא נוצרים מחדש בכל פריים), כדי שלא יהיה ריצוד בצבע או בצורה.

| שורה | עמודות | תוכן |
|---|---|---|
| 0 | 0-5 | עמידה (נשימה, לולאה) |
| 1 | 0-5 | הליכה (לולאה, פונה ימינה) |
| 2 | 0-2 | הכנה לירי (3 פריימים, האחרון = שיא ההכנה) |
| 2 | 3-5 | ירייה (3 פריימים) |
| 3 | 0-1 | פגיעה (2 פריימים) |
| 3 | 2-5 | מוות (4 פריימים: נופל, שוכב, מתפוצץ, נעלם) |

## מה המשחק משתמש בו עכשיו
עמידה (פריים 0 בשורה 0), הליכה (שורה 1), שיא ההכנה לירי (שורה 2 עמודה 2) ופגיעה (שורה 3 עמודה 0).
שורת הירייה ושורת המוות נשמרות בגיליון לשלב הבא (חיבור אנימציית ירייה ומוות במנוע).
